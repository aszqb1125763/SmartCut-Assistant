# 故障排查

## 程序无法启动

运行：

```powershell
.\setup_windows.ps1 -Check
```

若缺少环境，重新运行 `setup_windows.ps1`。安装日志位于 `logs`。

## 中文日志乱码

使用 `启动SmartCut.bat` 或打包版 EXE 启动。源码命令行建议使用 Windows Terminal / PowerShell，并保持 UTF-8。

## 模型请求 HTTP 400

常见原因是请求超过模型上下文、接口地址不兼容或模型名错误。先检查“设置 → 识别与模型”的提供方、地址和模型名；不要把 API Key 粘贴到公开问题中。

## 模型请求超时

长视频可把 API 超时提高到 180～300 秒。本地模型则检查显存、内存和模型文件是否完整。

## 大段静音没有删除

1. 确认 AI 听的是实际人声轨。
2. 重新分析旧索引。
3. 降低内容保留百分比只会加强内容压缩；长静音本身应由静音检测独立清理。
4. 查看任务报告中的静音候选、被保护原因和实际保留比例。

## Premiere 插件没有更新

完全退出所有 `Adobe Premiere Pro.exe` 进程，再重新打开。仅关闭面板通常不会重新加载 CEP 文件。

## 媒体脱机或工程打不开

确认源素材没有移动或改名，且输出工程与备份来自同一次任务。Premiere 中可使用“链接媒体”重新定位源文件。

## 提交问题时提供

- SmartCut 版本和启动方式。
- Windows、Premiere 和显卡信息。
- 去除密钥、个人路径和敏感台词后的相关日志。
- 能复现问题的最短步骤。
