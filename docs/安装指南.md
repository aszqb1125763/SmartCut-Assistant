# 安装指南

## 系统要求

- Windows 10/11 64 位。
- Python 3.10 以上，推荐 Python 3.12；用户无需预装，安装器会自动准备。
- 至少 8 GB 内存；长视频和本地大模型建议 16 GB 以上。
- FFmpeg。安装器会使用仓库内的 `bin`，没有时自动下载。
- 本地识别模型需要额外磁盘空间；NVIDIA 显卡可明显加快处理。

本地大语言模型只需安装一个：4B、8B 或 14B。软件内选择哪个档位，字幕、分析、编剧、剪辑和导演就统一使用哪个档位；不会要求同时安装 4B 与 8B。完全离线发行包也只携带打包时选中的一套模型。

## 一键安装

从 GitHub Release 下载 ZIP 后先完整解压，不要直接在压缩包预览窗口里运行。默认公开包是联网安装版，不带 EXE、`_internal`、虚拟环境、FFmpeg 或模型；第一次安装会从上游来源下载所需依赖和附件。

最简单的入口是双击 `安装并启动.bat`。它应完成环境检查、依赖安装、Premiere 插件安装并启动软件。需要自己选择安装位置时，双击 `安装到指定目录.bat`。

也可以在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_windows.ps1
```

脚本先检查安装文件是否完整；没有 Python 时先尝试通过 winget 为当前用户安装 Python 3.12。winget 不可用或失败时，会从 Python 官网下载 3.12.10 官方安装器、验证 Python Software Foundation 数字签名，再执行静默安装。随后创建 `.venv`、安装 `requirements.txt`、准备 FFmpeg、跟随软件设置下载一套语音模型、下载当前选择的一套本地语言模型，并安装 Premiere 插件。FFmpeg、llama.cpp 和 4B/8B/14B 本地模型都固定到明确版本、字节数和 SHA256；校验不一致会停止使用该文件，不会把“大小差不多”的下载当成成功。网络中断后可重新双击继续，不能删除用户已有配置。

新安装默认准备高准确率 `large-v3` 语音模型和 8B 本地语言模型。以后在软件里切换识别档或本地模型档位时，只补装新选择的一套，不要求同时安装多个本地语言模型。

安装可重复运行：依赖清单没有变化且完整时会跳过；更新了清单会再次检查和补装。`-Check` 不下载、不安装，仅检查现有环境。

常用参数：

```powershell
# 暂不下载语音模型
.\setup_windows.ps1 -NoModel

# 不创建桌面快捷方式
.\setup_windows.ps1 -NoShortcut

# 仅检查现有环境
.\setup_windows.ps1 -Check

# Premiere CEP 插件默认自动安装；此旧参数仅保留兼容
.\setup_windows.ps1 -InstallPremierePlugin
```

## 启动

双击 `启动SmartCut.bat`。启动脚本依次尝试：

1. 新命名的打包版 EXE。
2. 兼容旧发行包的 `智能剪辑助手.exe`。
3. 源码环境的 `.venv\Scripts\pythonw.exe app_main.py`。

如果环境尚未安装，它会打开 `setup_windows.ps1`。

## 手动安装

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe installer.py --no-launch
```

## 更新

保留 `conf`、模型和工作目录，替换源码后重新运行 `setup_windows.ps1`。不要把含 API Key 的 `conf/settings.json` 上传到公开仓库。

指定目录安装器会排除开发者的私人配置、工作目录、日志和备份；用户已有的设置由目标目录保留。覆盖安装前自行备份目标目录中的 `conf` 和工作数据。

使用 `安装器.py --dir "D:\Apps\SmartCut" --silent` 指定目录安装时，带 EXE 的发行包会完整复制同一次构建的 EXE 与根目录 `_internal`；`--no-runtime` 仅跳过独立 Python 环境，不会排除 EXE 必需的 `_internal`。缺少配套运行库、文件为空或复制失败都会报告安装失败，不能只取出 EXE 安装。

`--force` 更新会先暂存新运行库，随后将目标目录的旧 EXE 与 `_internal` 成套移入 `_安装备份_*`，再替换整套文件，避免混用不同版本的 DLL。替换失败会尝试恢复旧版，并报告备份位置；更新前请关闭 SmartCut。仅源码的安装包仍按源码方式安装，覆盖已有打包版时会把旧 EXE 和运行库移入同样的备份目录，之后启动脚本会使用源码环境。

## 卸载与回滚

本工具以项目目录为主，不需要删除系统 Python。卸载前保存自己的工程、素材和模型，随后删除确认不再需要的 SmartCut 安装目录与桌面快捷方式。Premiere 插件安装在当前用户的 CEP 扩展目录，需另行移除 `com.smartcut.prbridge` 后重启 Premiere。

回滚应恢复同一次构建的整套 EXE 与 `_internal`，并保留自己的 `conf` 和工作目录。不要把不同版本的二进制和运行库混用。
