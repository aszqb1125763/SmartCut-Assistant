# API 模型配置

默认提供方是“本地模型”，不会调用外部模型接口。在“设置 → 识别与模型”中可以切换为 API。

## 本地模型只选一个

在“本地模型”窗口选择 4B、8B 或 14B 后，字幕校对、素材分析、编剧、剪辑师和导演全部使用这一套模型。软件不会再为某个岗位暗中启动另一档模型，因此新电脑只需下载所选的一份 GGUF。8B 是默认推荐档；4B 更快，14B 更强但更占显存。切换档位只影响下一次任务，运行中的任务不会中途换模型。

所选模型文件缺失或不完整时，软件会明确提示重新下载，不会静默回退到其他档位。`setup_llm.py smart`、`setup_llm.py fast` 或 `setup_llm.py large` 可在命令行准备对应的唯一模型。

## 配置字段

| 字段 | 配置键 | 说明 |
| --- | --- | --- |
| 提供方 | `llm_provider` | 本地或具体 API 服务 |
| 接口地址 | `llm_api_base_url` | 可使用预设，也可手动修改 |
| API Key | `llm_api_key` | 密码框显示；部分本地兼容服务可留空 |
| 模型名 | `llm_api_model` | 服务商实际模型 ID |
| 请求超时 | `llm_api_timeout` | 5～600 秒，默认 120 秒 |

## 支持的预设

本地、OpenAI 兼容自定义、OpenAI、DeepSeek、通义千问、硅基流动、Moonshot/Kimi、智谱 GLM、Ollama/vLLM、Anthropic Claude、Google Gemini。

预设只负责填充常见地址，模型名和账号权限仍以服务商控制台为准。私有网关或反向代理可以直接修改接口地址。

例如 DeepSeek 的模型 ID 可填写服务商当前提供的 `deepseek-chat`；Ollama 填写本机已经拉取的模型名。OpenAI 兼容地址可以填写 `/v1`、智谱的 `/api/paas/v4` 或完整 `/chat/completions` 端点。Claude 使用原生 Messages 协议，Gemini 使用原生 generateContent 协议，不能直接填写一个网页聊天地址。

## API 模式的岗位分工

切换为 API 后，所有语言理解与剪辑决策请求都由所选接口负责：

- 分析员：校对转写、识别内容类型，整理中立素材证据。
- 编剧：分批通读时间轴，建立章节、主线与必要的因果关系。
- 剪辑师：依照主题、信息密度和保留百分比决定删留，提交可校验的剪辑单。
- 导演：复审内容与接缝，提出有证据的修复意见。

远端使用独立的 API 角色提示，不发送旧本地模型的 system 提示。事件 ID、时间坐标和输出字段仍由程序校验，这些是执行时间轴所需的接口合同。无效结果会重试一次；请求或合同失败会明确报错，不会暗中启动 llama-server 或切回本地语言模型。切换服务商、模型或接口配置后，不复用另一后端的剧本、决策及任务恢复结果。

API 模式不加载历史训练的 `conf/editor_model.json` 或 `conf/cut_value.json` 来决定删留，也不读取旧索引中的训练分或运行本地规则兜底评分。旧格式仍需要的 `scores` 数组统一填入 `0.5`，并标注 `scores_source=api_neutral`；这是中立占位，不能当作 API 的评分，也不代表保留 50%。依赖本地评分阈值的剧本筛选、低分跑题删句和按段价值压预算在 API 模式停用；超预算应交给 API 剪辑师和导演返工。审片抽样也不按历史训练分挑高分句。切回本地模式后原有训练模型仍可使用。

完整智能任务在 API 模式统一调用模型剪辑师，即使旧调用方传入 `model_editor=False` 也不会切回本地评分。传统的按句分数、按卡片分数或本地力度筛选入口会明确提示改用「智能剪辑」；命令行使用 `autopilot.py <素材路径>`，不要用 `autocut.py` 的传统评分剪辑流程。

媒体提取、Whisper 语音转写、OCR/音画特征、波形边缘保护、坐标校验和 PR 时间轴执行仍在本机完成。它们为 API 提供证据并保护源素材，因此 API 模式也需要安装 FFmpeg 与语音模型；本地语言模型 GGUF 和 llama-server 则不是 API 模式的必需项。

## 连接失败时

先核对模型 ID、接口地址、Key 权限与账户额度。401/403 通常与鉴权有关，404 常见于地址或模型不存在，400 表示服务商不接受本次请求。429 或临时服务错误会有限重试，持续失败时保留任务记录并停止相关 AI 阶段。

界面与 `logs/ai-api.log` 会给出脱敏错误。自定义鉴权头可通过 `conf/llm.json` 的 `api.headers`，或环境变量 `SMARTCUT_AI_HEADERS`（JSON 对象）提供。环境变量 `SMARTCUT_AI_PROVIDER`、`SMARTCUT_AI_BASE_URL`、`SMARTCUT_AI_API_KEY`、`SMARTCUT_AI_MODEL`、`SMARTCUT_AI_TIMEOUT` 可覆盖本机设置，便于不把 Key 写入配置文件。

## 安全说明

- Key 保存在本机 `conf/settings.json`，当前未接入 Windows 凭据库。
- 普通状态栏和日志不会输出 Key。
- `conf/settings.json` 已加入 `.gitignore`。
- 公开错误报告前仍应检查日志和截图是否包含自定义接口中的敏感查询参数。

## 数据范围

当前网关发送文本和结构化素材证据，包括台词、标签、时间轴摘要及本地提取的音画特征，不直接上传原始整段视频或音频。涉及隐私素材时请使用本地模型或自建服务，并阅读服务商的数据政策。

内置预设及三类协议已通过模拟请求验证；具体模型权限、费用和服务端兼容性需要使用自己的账号连接确认。
