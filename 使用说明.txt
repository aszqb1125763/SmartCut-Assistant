一、怎么打开（正式版）
================================================================

  装好后有三种打开方式，效果都一样：

  1) 双击桌面上的「智能剪辑助手」
  2) 开始菜单搜「智能剪辑助手」
  3) 进安装目录，双击 智能剪辑助手.exe

  注意：
  · 第一次打开要 5~15 秒（加载模型和索引），会先看到一个启动画面
  · 如果双击没反应，运行同目录的「启动（排错用）.bat」，
    它会把错误信息留在窗口里，方便看出缺什么

  关于版本：菜单 帮助 → 关于 智能剪辑助手

智能剪辑助手 · 一站式版 —— 使用说明（全版）
========================================================
只想快点上手 → 看「使用说明-简易版.txt」（只讲点哪里）。
本文件：点法 + 下载清单 + 安装 + 目录 + 设置全解 + 剪辑规则 +
        BGM + 字幕 + 命令行 + 自测 + 排错 + 备份 + 指标口径。


一、这套东西是什么
--------------------------------------------------------
把一段几十分钟的录播，自动剪成一条能直接发的成片：

    录播 → 转写台词 → 排卡片 → 语义分析/写剧本 → 按力度挑内容
         → 切点对到气口 → 逐段编码 → 拼接 → 配 BGM → 出片（可带字幕）

全部本地跑：语音识别用 GPU（faster-whisper），语义/剧本用本地大模型
（llama.cpp + Qwen3），视频用 FFmpeg。不联网也能用（模型已下好时）。


二、必须先有的东西（下载清单 + 在哪儿补）
--------------------------------------------------------
| 组件 | 位置 | 大小 | 缺了会怎样 | 怎么补 |
|---|---|---|---|---|
| 语音识别模型 large-v3 | models\large-v3-full\ | 约 2.9 GB | 不能转写台词 | 第一次点「开始分析」时自动下载 |
| 语音识别 turbo（可选） | models\large-v3-turbo-full\ | 约 1.5 GB | 快、略糙 | 同上（自动下载） |
| 本地大模型 Qwen3-4B（快速档） | models\llm\Qwen3-4B-…gguf | 2.33 GB | 语义/剧本变慢 | 菜单 工具 → 本地模型… → 点「下载」 |
| 本地大模型 Qwen3-8B（精细档） | models\llm\Qwen3-8B-Q4_K_M.gguf | 4.68 GB | 同上 | 同上 |
| 模型推理器 llama.cpp | bin\llama\ | 约 798 MB | 语义/剧本/导演全失效 | 双击「安装到指定目录.bat」重装（默认带） |
| FFmpeg | bin\ffmpeg.exe、bin\ffprobe.exe | 约 100 MB | 不能剪、不能抽音轨 | 重装时默认带 |
| Python 运行环境 | .venv\ | 约 3 GB | 程序起不来 | 重装时自动建 |
| BGM 曲库（可选） | 自选 mp3 文件夹 | 自定 | 只是没背景音乐 | 菜单 工具 → 设置… → BGM 曲库「选择…」 |

合计约 11~12 GB，全部在安装目录内（绿色版，不写 AppData、不写系统临时目录）。

怎么确认齐了：
  · 打开程序看底部状态栏：有「⚠ 本地模型不可用…」就是缺，同一行会写缺 exe 还是 gguf；
  · 菜单 帮助 → 打开日志目录 → 看 ui_errors.log 里的自检记录。


三、安装
--------------------------------------------------------
【图形】双击「安装到指定目录.bat」→ 选目录 → 开始安装 → 等它装完。
【命令行】安装器.py 参数：

    --dir <目录>     安装到哪（默认同目录下新建）
    --silent         不弹界面
    --no-bin         不复制 ffmpeg
    --no-llama       不复制 bin\llama（省 800 MB，但索引会缺语义分/剧本，不建议）
    --no-model       不预先下载语音模型
    --no-shortcut    不建桌面快捷方式
    --force          目标目录已有东西也强制覆盖
    --launch         装完直接启动

安装器默认会复制：程序本体、bin（ffmpeg + llama）、conf 干净配置、
venv（环境已建好就直接用）；models 里有模型就一起带过去。

绿色版：整个安装目录可以整体拷到别的盘/别的机器（同系统、同显卡驱动前提下）。
卸载：删掉安装目录即可（不写注册表、不写 AppData）。

五、从打开到出片：一步一步点
--------------------------------------------------------
【第 1 步】打开素材
    把文件拖进窗口，或 菜单 文件 → 打开素材…（可多选）
    已经分析过的，用 菜单 文件 → 打开已有索引…

【第 2 步】分析
    点左栏「开始分析」（也可 菜单 工具 → 重新索引 重跑一遍）
    底部会显示 [用时] 当前阶段；同一份素材只需分析一次

【第 3 步】挑卡片（可选）
    卡片区里：
      点「全选」/「全不选」快速选
      点「只看高光」只显示评分高的
      双击卡片 → 看这一帧；右键 → 更多操作
      队列里可以用「上移」「下移」「移除」「清空」调整顺序

【第 4 步】出片
    「智能剪辑」= 用索引里的剧本/分数/力度直接剪（推荐）
    「导演剪辑」= 先让本机大模型通读一遍再剪（多 2~4 分钟）
    出片过程中底部有进度和已用时间；想停就点「停止」

【第 5 步】拿成品
    完成后点「打开文件夹」；成片旁会有 _字幕.srt / .ass
    想重新出：改 剪辑计划.json 里的 action，然后
      菜单 工具 → 重新索引 旁边那条命令行：autocut.py <索引目录> --plan
      （或命令行直接跑，见第十节）

【其它常用点击】
    文件 → 播放文件…         用内置播放器看原片
    文件 → 打开工作目录       直接跳到索引/临时目录
    工具 → 音轨…              选哪几条音轨参与剪辑/导出
    工具 → 字幕…              导出 SRT/ASS、烧录字幕
    工具 → 字幕纠错           用本机大模型修错别字
    工具 → 本地模型…          看/下载/切换大模型档位
    工具 → 设置…              力度、时长上限、字幕烧录、BGM…
    帮助 → 使用说明（简易/全版）、待改记录、打开日志目录、功能自测…


六、设置全解（在 菜单 工具 → 设置… 里）
--------------------------------------------------------
| 设置项 | 默认 | 点了会怎样 | 什么时候改 |
|---|---|---|---|
| 片段导出/合并/智能剪辑/训练目录 | 空 | 各类导出的存放位置 | 想集中放某个盘 |
| 片段最长 | 45 秒 | 一张卡片最长多少秒 | 想要更碎/更整 |
| ± 容差 | 6 秒 | 上面那个的上浮 | 一般不动 |
| 卡片切法 | 按段落 | 段落 / 按句子 | 想更细选按句子 |
| 剪辑力度 | 轻度 | 轻度/中度/重度（见第七节） | **最常用** |
| 时长上限 | 不限 | 不限=按内容；填数字=超出才裁 | 想固定片长 |
| 导演·跳过读片 | 不勾 | 勾上省 2~4 分钟 | 赶时间 |
| 缩略图 | 不勾 | 生成卡片缩略图（很慢） | 想眼看挑片 |
| 字幕·烧进画面 | 不勾 | 勾上=字幕印在画面上 | 直接上传平台 |
| BGM·自动配 | 勾 | 出片铺背景音乐 | 不想配乐时取消 |
| BGM 曲库 | 示例路径 | 点「选择…」换文件夹 | 换自己的曲库 |
| BGM 音量 | -22 dB | 越小越轻 | 觉得吵调 -25/-28 |
| 音量均衡 | 勾 | 不同曲子按响度拉齐 | 个别曲子偏小时保持 |

保存会合并写入 conf\settings.json（不会丢别的键）。
BGM 细节（段长、循环淡化、闪避开关）在 conf\bgm.json。


七、三种剪辑力度（核心规则）
--------------------------------------------------------
| 力度 | 做什么 | 实测（22.6 分钟素材） |
|---|---|---|
| 轻度 | 只删空屏（静音、无画面变化），说话内容几乎全留 | 内容保留 ≈ 原片说话量 |
| 中度 | 再删明确废话、跑题、重复；按剧本章节取舍 | 约 18 分钟（接近人工成片） |
| 重度 | 只留每章关键节点 | 约 10~11 分钟 |

三档都保证：
  · 开头是自我介绍（从"哈喽…"那句开始，不会被切掉）
  · 时间顺序不乱（片头 → 中间剧情 → 收尾）
  · 切点不落在句子中间；切点吸附到气口（≥0.45 秒停顿）
  · 每章只要有内容留下，就保留这章的开头（交代这章做什么）

"时长上限"的含义：
  · 不限（默认）：按内容走，宁可长也不丢剧情
  · 填数字：只有超过这个长度，才按"段落价值"从低往高裁


八、BGM 怎么配的
--------------------------------------------------------
1. 扫曲库每首 mp3，按秒算能量，挑"最平稳的一段"（避开前奏/静音/忽大忽小）
2. 曲内起伏拉平（2 秒窗口慢速 AGC）
3. 按响度（LUFS）对齐到目标电平（默认 -22 dB 档；不同曲子响度跨度 3.4 → 1.0 dB）
4. 交叉淡化循环铺满全片（默认 2 秒淡化）
5. 混进成片：视频流复制，只重编码音频（快）
6. **不做闪避**（固定电平）：conf\bgm.json 里 duck_db 保持 0

试过但没采用：把循环接缝吸附到曲子能量谷——实测接缝跳变均值没变（1.8 dB），
默认关（想试把 conf\bgm.json 的 seam_snap 改 1）。


九、字幕
--------------------------------------------------------
· 不勾"烧进画面"：出片时在成片旁生成 `<成片名>_字幕.srt` 和 `.ass`
· 勾上"烧进画面"：字幕直接印在画面（每段各自烧，不额外多一遍编码）
· 准确档默认用 large-v3 + beam 5，并保存词级时间；疑似漏字、低置信词和异常时间只重听附近短窗口，不重跑整部素材
· 校对会结合用户词表、本片术语和前后文；模型不能概括、删字或新增省略号，失败时回退原始识别结果
· 默认按标点、实际停顿和语义转折断句，尽量做到“一句一个意思”，单行约 15 字；有词级证据时按真实词边界定时
· 简体、繁体字幕使用同一组时间点；字幕出错会记录警告，不会阻止普通视频或可编辑 PR 工程保存
· 样式在 conf\subtitle_style.json（字体、字号、每行字数、颜色、描边、位置）
· 菜单 工具 → 字幕… 可以单独导出/烧录

已知：字幕样式对话框在 1.0 里暂时封存（可直接改 conf\subtitle_style.json）。


十、命令行（不打开界面也能剪）
--------------------------------------------------------
    .venv\Scripts\python.exe autocut.py <索引目录> --out 成片.mp4
        --cut-level light|medium|heavy    剪辑力度
        --preview                         低分辨率快出（试剪用）
        --dry-run                         只算不渲染
        --tracks 2,3                      用哪几条音轨（从 1 起）
        --plan                            按 剪辑计划.json 里的 action 重出
        --no-bgm                          这次不配 BGM
        --force-crossfade                 全部叠化

索引：    .venv\Scripts\python.exe index.py <视频> -o <索引目录>
声学特征：.venv\Scripts\python.exe audiofeat.py <索引目录>
精确边界：.venv\Scripts\python.exe audiofeat_bounds.py <索引目录>
字幕纠错：.venv\Scripts\python.exe proofread.py <索引目录>
功能自测：.venv\Scripts\python.exe selftest_cut.py [组名]


十一、功能自测（改完代码跑一条）
--------------------------------------------------------
界面里：菜单 帮助 → 功能自测…（结果会贴到状态栏，也写进 logs\selftest_last.txt）

    cd 安装目录
    .venv\Scripts\python.exe selftest_cut.py

十二、排错
--------------------------------------------------------
日志位置（菜单 帮助 → 打开日志目录 直接跳过去）：
    index_日期_时间.log   每次分析的完整过程（带每步耗时）
    ui_errors.log         界面/剪辑报错的完整堆栈
    selftest_last.txt     最近一次功能自测的输出

症状 → 处理：
  · 分析很久没动静
        看 index_*.log 最后一行停在哪；抽帧在机械盘上可能要几分钟。
        程序启动会自动清掉上次残留的模型服务，不用手动杀进程。
  · 中度和重度出片一样
        索引缺语义分/剧本（本地大模型没装/没起来）。
        → 菜单 工具 → 本地模型… 下载并用；缺推理器就重装 → 重新分析。
  · 出片报错（某某 Error）
        看 logs\ui_errors.log 的行号，把那段发我。
  · 成片开头不是问候
        片头识别已修（往前兜到第一句说话）；若还出现，说明素材开头静音超 25 秒。
  · 字幕对不上
        索引是旧版（无精确边界）→ 重新分析。
  · 磁盘占用大
        工作目录\_temp 自动清；索引和成片按需清理。


十三、备份、恢复、迁移
--------------------------------------------------------
· 版本快照：每次改完代码运行 dev_finish.py 会存一份到 ..\_版本备份\vNNN_…

十四、指标口径（怎么判断"剪得像不像你"）
--------------------------------------------------------
全部是可复现的数字，不是"感觉"：

1) 标准答案：把成片台词和原片台词做序列对齐（difflib），
   对齐上的原片句子 = 你实际留下的内容。三期对齐覆盖率 78%~93%。
2) recall / precision / F1：以"你留下的"为标准答案。
   同样长度下，目前 recall 0.66~0.80、precision 0.45~0.68。
3) 切点质量：切点处静音长度（人工中位 1.22~2.59 秒，我们改后 1.24~1.53 秒）、
   切点落在"有声帧"上的比例（66% → 40%）。
4) 结构：开头是否自我介绍、时间顺序是否正常、每章是否保留开头。

局限（重要）：这些指标衡量"留的内容像不像你留的"，
**不衡量"好不好看、听着顺不顺"**——那部分只能靠人耳/人眼。

有不明白的直接问，我按你的实际素材调。
========================================================

【术语纠错（字幕错别字）】
软件自带一份从 90 个整合包扒出来的词典（13 万个物品/方块/实体名，kb\术语_全量.txt）。
分析时，语音识别出的台词会自动按拼音纠错：
  过冲水晶 → 过充水晶      乌妖电容 → 巫妖电容      ATM定 → ATM锭
默认只改 4 个字以上的专有名词（少改少错），日志里会写「拼音纠错：改了 N 处」。
想更激进：把 terms.py 里 correct() 的 min_len 改成 3（会多纠 3 字名，也可能误改普通短语）。

【三档的具体含义（软件实际行为，可验证）】
· 轻度：只删空屏和静音，所有说话内容全留（≥95% 说话时长）。
        适合"只想去掉发呆/加载画面"。
· 中度：按游戏实况体裁剪到 15 分钟左右（原片越长压得越狠）；
        每章至少保留 22%，开场/本集目标/结果/下期预告这些"叙事骨架"必留。
        适合日常连载。
· 重度：只留叙事骨架 + 高分内容，约 7~8 分钟（不超过说话时长 45%、章节保底 12%）。
        适合做"高光/合集"。
实测（第 11 期 33.5 分钟素材）：轻度 26.3 / 中度 14.7 / 重度 7.6 分钟，
骨架覆盖 中 100% / 重 100%。三档保证单调（轻 > 中 > 重），不会出现两档一样。

【自动任务（一条命令跑完）】
以前要分三步：先分析、再点智能剪辑、再自己配 BGM。现在两条路：
· 界面：菜单「工具 → 自动任务：分析 → 剪辑 → 出片…」，选素材就行
· 命令行：python autopilot.py "素材.mp4"
         加 --level heavy 出重度版；--no-bgm 不配 BGM；给目录就批量
它会一次跑完 分析 → 剧本 → 剪辑计划 → 转场 → 出片（字幕 + BGM），
并在素材旁边生成「XXX_自动任务.md」，写清每阶段耗时和剪辑决策。
实测 9.4 分钟素材约 2 分钟出片。
