智能剪辑助手 · 简易版说明（只讲怎么点）
========================================
不想看一堆目录和原理，就照这份点。
（想看路径、原理、命令行 → 同目录「使用说明.txt」全版）


一、第一次打开：先点三下
------------------------------------------------
【第 1 下】菜单栏 工具 → 本地模型…

    弹出一个"本地模型档位"窗口，里面列着几档模型：
        · 标"已下载 x.x GB" = 这台电脑已经有了
        · 标"未下载（约 x GB）" = 还没有

    要下的就点它 → 点右下角「下载」→ 等进度条走完
    下完再点「使用这个」（会打个 ★，表示以后就用这档）
    提示：显存小就选小的那档；不确定就选"快速/平衡"字样的。

【第 2 下】菜单栏 工具 → 设置…

    这里只要先定两个地方：
        · 剪辑力度  → 建议选「中度」（删废话，长度接近你成片）
        · 时长上限  → 建议留「不限」（按内容走，不硬凑时长）
    其它先不用动，点「保存」。

【第 3 下】菜单栏 帮助 → 功能自测…

    它会在后台跑一遍，跑完状态栏会显示"自测通过"或"有问题"。
    显示"自测通过"就说明这台电脑能正常干活了。


二、每次剪一条片子：五步
------------------------------------------------
  1. 把录播视频**拖进窗口**（或者 菜单 文件 → 打开素材…）
  2. 点「开始分析」
       底部进度条会动，左边写着当前在干什么、已经用了多久
       22 分钟的素材大约 2 分钟；74 分钟的大约 8 分钟
  3. 分析完，中间会排出一堆卡片（一段一张）
       想全要就点「全选」；想只看精彩的先点「只看高光」
       不挑也行，直接下一步
  4. 点「智能剪辑」（或「导演剪辑」）
       力度、时长上限用的就是设置里那两个
  5. 等出片，状态栏走完 → 点「打开文件夹」看成品
       成品旁边会自动多一个 _字幕.srt（不烧字幕时）


三、设置里每个开关，点了会怎样
------------------------------------------------
打开：菜单 工具 → 设置…

  · 剪辑力度
        轻度 = 只把没声音的空屏剪掉，说话内容几乎全留（最完整）
        中度 = 再删掉废话、跑题、重复（推荐，长度接近你成片）
        重度 = 只留每章最关键的部分（最短）
        点完保存，下次剪辑生效（不用重新分析）

  · 时长上限
        不限 = 按内容走，不硬凑（推荐）
        填数字 = 超过这个分钟数才裁，比如填 15 就是控制在 15 分钟内

  · 导演：跳过读片
        不勾 = 先让本机大模型通读一遍再剪（多 2~4 分钟，结果更稳）
        勾上 = 跳过读片直接剪（赶时间用）

  · 缩略图：生成缩略图
        勾上 = 卡片会有小图预览，但很慢（一句一张要几分钟）
        平时不用勾，双击卡片也能立刻看到那一帧

  · 字幕：出片时把字幕烧进画面
        勾上 = 字幕直接印在视频上（B站/抖音能直接传）
        不勾 = 只生成 _字幕.srt 文件放成片旁边（进剪辑软件用）

  · BGM：自动配 BGM
        勾上 = 出片自动铺背景音乐；取消 = 不配

  · BGM 曲库 → 点右边「选择…」选你放 mp3 的文件夹

  · BGM 音量
        默认 -22，数字越小越轻
        觉得吵：调到 -25 或 -28

  · 音量均衡：按响度拉齐
        勾上 = 不同曲子听起来一样响（推荐保持勾选）
        取消 = 个别曲子会显得小声


四、出问题，先点这几下
------------------------------------------------
  · 状态栏出现「⚠ 本地模型不可用」
        → 双击程序旁边的「安装到指定目录.bat」重装一次
          （它默认会把缺的组件补齐），装完重开程序

  · 分析一直转圈不动
        → 菜单 帮助 → 打开日志目录，看最新的 index_*.log 最后一行停在哪
          然后关掉程序重开（重开会自动清掉上次残留的进程）

  · 中度和重度剪出来一样长
        → 说明这份素材的"分析"没跑全（缺语义和剧本）
          → 点「重新索引」重新分析一次，再去剪

  · 剪出来开头不是"哈喽…"
        → 先把这条素材重新分析一次（旧索引没有新的片头保护）

  · BGM 太吵 / 太轻
        → 菜单 工具 → 设置… → 调「BGM 音量」→ 保存 → 重新剪一条

  · 想确认功能有没有坏
        → 菜单 帮助 → 功能自测…（等状态栏出结果）


五、哪些东西需要联网下（点了才下）
------------------------------------------------
  · 语音识别模型：第一次点「开始分析」时，如果本机没有，会自动下载
        （等它下完就行，之后不用再下）
  · 本地大模型：菜单 工具 → 本地模型… 里点「下载」
        （下完点「使用这个」）
  · 其它（剪视频的组件、运行环境）安装时就带好了，不用管
